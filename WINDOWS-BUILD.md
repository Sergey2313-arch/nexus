# NEXUS — сборка Windows x64

## Скачать и запустить

1. Откройте Actions → Windows build → последний успешный запуск вашей ветки.
2. Скачайте артефакт **NEXUS-Windows-x64** внизу страницы запуска.
3. Распакуйте скачанный архив, затем `NEXUS-win-x64.zip` целиком в отдельную папку.
4. Запустите `NEXUS.exe` из этой папки. Соседние DLL и каталоги нужны для работы.

Это тестовая неподписанная сборка для Windows x64. Visual Studio не требуется; .NET и Windows App SDK включены в папку. Проверка комплектации в CI не заменяет запуск на пользовательском Windows. Не перемещайте EXE отдельно от остальных файлов. Запуск из архива не поддерживается.

`BUILD.txt` содержит commit и номер сборки; `SHA256SUMS.txt` — контрольную сумму внутреннего ZIP.

## Проверка на компьютере

- Откройте датчики: температура CPU 0 °C и частота 0 MHz означают отсутствие текущего показания. Нулевая нагрузка остаётся допустимой.
- На ноутбуках GPU VR SoC отображается отдельно от ядра GPU. Если датчик ядра отсутствует, общая оценка оборудования остаётся частичной.
- В диагностике галочки появляются по мере выполнения этапов. Жёлтый `!` означает частичную проверку; причина отображается в строке этапа.
- В очистке нажмите «Показать приложения», выберите процесс и проверьте статус рядом с кнопками. После уменьшения рабочего набора память может снова потребоваться приложению.
- SFC, DISM и журнал Security требуют прав администратора. Права не делают неподдерживаемые датчики доступными автоматически.

Данные и отчёты сохраняются в `%LocalAppData%\NEXUS`. ИИ подключается через вкладку помощника: укажите endpoint, название реально установленной/доступной модели и ключ, если сервис его требует. Запрос отправляется только по кнопке; локальный план NEXUS работает без модели.

## Собрать самостоятельно

```powershell
dotnet publish NEXUS/NEXUS.csproj -c Release -r win-x64 --self-contained true -p:Platform=x64 -p:PublishProfile= -p:WindowsAppSDKSelfContained=true -p:PublishTrimmed=false -p:PublishReadyToRun=false -p:PublishSingleFile=false -o artifacts/NEXUS-win-x64
```

Для сборки нужны .NET SDK 8 и Windows SDK. Для WinUI с отражением и обычными XAML Binding обрезка сборок отключена: иначе Debug и Release могут вести себя по-разному.

## Подключение ИИ

1. На вкладке помощника укажите полный URL `chat/completions` и ключ, если нужен. Сервер и модель должны быть уже доступны; NEXUS не устанавливает их.
2. «Загрузить список моделей» запрашивает совместимый `/models` (15 секунд, до 200 имён). Отсутствие поддержки списка не мешает ручному вводу модели.
3. «Проверить ответ модели» отправляет короткий вопрос без показателей ПК и истории (до 120 секунд). Список моделей сам по себе не подтверждает работоспособность генерации.
4. Сохраните адрес и модель. В `%LocalAppData%\NEXUS\ai-connection.json` записываются только эти два значения. Ключ, чат и галочка передачи контекста не сохраняются. При следующем запуске сетевых запросов автоматически нет.
5. Для диагностики можно включить краткий контекст и посмотреть его снимок перед отправкой. Снимок показателей обновляется при отправке; пути, IP и буфер обмена в него не входят.

Совместимый формат сверяется с [документацией Ollama](https://github.com/ollama/ollama/blob/main/docs/api/openai-compatibility.mdx).
