# NEXUS — диагностика системы

Dashboard → «ПРОВЕРИТЬ СИСТЕМУ». Восемь этапов: процессы; автозагрузка и задания; автоматические службы; файлы; TCP-соединения; Defender; настройки защиты, SFC/DISM и Security events; корреляция файлов между источниками. Отмена завершает дочерний PowerShell. Лимит обычного этапа 60 секунд, этапа SFC/DISM — 10 минут.

## Безопасность

- Autostart: Win32_StartupCommand, Run/RunOnce (включая 32-bit HKLM Run), включённые задания планировщика.
- Файлы: Temp/Desktop/Documents/Downloads, рекурсивно до 1000 кандидатов суммарно и 500 каталогов на корень. Reparse points пропускаются. EXE/DLL/SYS/PS1/VBS/JS/BAT/CMD проверяются Authenticode. Неподписанный файл — признак для ручной проверки, не диагноз malware.
- Процессы: пути файлов, маскировка системными именами вне Windows, кодированные команды PowerShell с PID/ParentPID (собственный сборщик NEXUS исключён).
- Сеть: установленные TCP-соединения и owning PID. Репутация IP, UDP и прослушиваемые порты не анализируются.
- Defender: включение защиты, возраст баз, исторические обнаружения с незавершённым действием.
- Брандмауэр/UAC; SFC /verifyonly и DISM /Online /Cleanup-Image /ScanHealth; события 4625/1102 за 7 дней (до 100).
- SFC/DISM и Security log требуют администратора. Автоматического восстановления, отключения защиты, удаления или запуска найденных файлов нет. Команды диагностики могут писать стандартные системные журналы.

При ошибке этап помечается частичным; находки, полученные до ошибки, сохраняются. Защищённые процессы и сложные launch-команды могут не дать путь. Отсутствие находок не доказывает отсутствие взлома. Исторические события требуют проверки контекста.

## Железо и Health Score

Снимок доступных CPU/GPU/storage temperature, остаточного ресурса SSD, занятости фиксированных дисков и RAM. Рекомендации при перегреве, снижении ресурса, недостатке места и высокой загрузке памяти. Это один снимок, не стресс-тест и не прогноз отказа. Используются существующие датчики LibreHardwareMonitor.

Security score: 100 минус штрафы за уникальные Warning (+10) и Critical (+30), с ограничением 0–100. Hardware score аналогичен по находкам железа. Общий Health Score — минимум двух оценок, только когда завершены этапы безопасности и доступны все ключевые типы показателей; иначе «недостаточно данных». Отдельные оценки показываются с указанием частичного покрытия.

## Отчёты

После сканирования автоматически сохраняются HTML и JSON в `%LocalAppData%\NEXUS\Reports`. «Открыть отчёт» открывает HTML. Содержимое событий, команд и путей HTML-экранируется. Отчёты содержат имена компьютера, пути и соединения; перед передачей ознакомьтесь с содержимым. Итог и находки записываются в SQLite, фильтр «Безопасность».

## Проверка

Windows CI: Debug x64 build и console checks (неполные данные, пороги температуры, пределы риска, JSON, отмена, HTML escaping, синтаксис PowerShell). Реальная работа датчиков и UI проверяется на Windows вручную: запуск без/с правами администратора, отмена/повтор/закрытие окна, сопоставление с Windows Security и SMART утилитой. Не отключайте защиту специально для проверки.
